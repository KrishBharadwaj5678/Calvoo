<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Calvoo/raw/main/favicon/favicon.svg" width="40"/> Calvoo</h1>

<p align="center">
  Calvoo é uma calculadora moderna e responsiva, desenvolvida para oferecer cálculos rápidos e precisos através de uma interface limpa e intuitiva.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Calvoo/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| ------------------------- | ----------------------------------------------------- |
| ➕ Operações Aritméticas | Realize adição, subtração, multiplicação e divisão com facilidade |
| ✨ Animações Suaves | Interface dinâmica e agradável com animações desenvolvidas com GSAP |
| 🎨 Interface Limpa | Design simples, moderno e fácil de usar |
| 📱 Design Responsivo | Funciona perfeitamente em computadores, tablets e dispositivos móveis |
